Privacy

This page describes the public website at welliepos.com as of 7 November 2026. It does not describe the Wellie point-of-sale app. The site says that app is still in development, and this page does not set out the app's data practices.

Who to contact

The site calls itself Wellie and names Las Vegas, Nevada. Email hello@welliepos.com.

Hosting

GitHub Pages hosts this website. The publishing source is the main branch, and HTTPS is on for welliepos.com. GitHub's privacy statement describes how GitHub handles connections to Pages. This page does not restate GitHub's practices.

What these pages do

The pages are static HTML, CSS, images, and a font file stored with the site. The home page script changes colors as you scroll when your device is set to a light appearance. That script does not set a cookie and does not send information to Wellie.

These pages do not include an analytics tag, an advertising tag, or a form.

Email

Request a demo, and the email address in the footer, are links that open your email app with a message addressed to hello@welliepos.com. Your email provider sends that message. This website does not receive it through a form.
